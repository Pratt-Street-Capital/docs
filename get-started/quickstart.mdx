This guide walks you through signing up for Trekton, getting your API key, and making your first API request. By the end, you will have queried negotiated rate data and know how to explore the dashboard.

<Steps>
  <Step title="Sign up">
    Visit [https://pratt-street-capital.github.io/radius-demo/](https://pratt-street-capital.github.io/radius-demo/) to request access. The Trekton team will set up your account and provision API access.
  </Step>
  <Step title="Receive Your Credentials">
    After talking to the sales team, your email will be given a green light to log in.
  </Step>
  <Step title="Explore the dashboard">
    Log in to the Trekton dashboard to browse facilities, payers, and supply insights without writing code. Use the dashboard to validate what you see in API responses.
  </Step>
</Steps>

<Tip>
  Start with a small state and single CPT code to keep response sizes manageable while you learn the data shape.
</Tip>
